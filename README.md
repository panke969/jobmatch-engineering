# JobMatch MVP

This is a local/static MVP of the Engineering Job Matching System.

## Included
- Paste a vacancy and calculate a heuristic engineering match score.
- Match-by-category breakdown.
- Gap/risk detection.
- Recommended portfolio projects.
- Job Tracker using browser localStorage.
- Basic market-insight aggregation from saved vacancies.
- Responsive dashboard.

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.
