# JobMatch Engineering — v0.3

Workflow:
**find new jobs → rank them → show them on the site → manually manage the rest.**

## New in v0.3
- One-click Latest Jobs feed
- 12 engineering role searches in parallel
- Duplicate removal
- Match + freshness + salary ranking
- Shows how recently a job was posted
- Shows which role query discovered the vacancy
- Keeps English/Dutch, salary and excluded-industry filters
- Manual tracker remains editable
- No LinkedIn scraping or automation

## Search families
Mechatronics, Integration, Automation, Project, Mechanical, Service,
Field Service, Commissioning, Test, NPI, Manufacturing and Systems Engineering.
